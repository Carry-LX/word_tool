# Template Narrative Mapping

本文件记录 `data/同济大学XX学科的国际排名发展分析-2026年5月.docx` 中，正文说明段与图表槽位的严格对应关系。

对应的机器可读映射文件：

- `configs/template_slot_inventory/narrative_paragraph_mapping.json`

## 结论

当前模板里的正文说明段，不适合用“找最近一段”的启发式替换，原因有三类：

1. 有些说明段在图题/表题前，例如 `L001/L002/L003/L004/L005`。
2. 有些说明段在图题后，例如 `L006/L007/L012`。
3. 有些逻辑槽位在模板里没有独立说明段，例如 `L023` 附表。

此外，模板本身还存在几处内容不一致：

- `P35` 图题写成“软科”，但对应正文 `P33` 明确属于 QS。
- `P56` 是 QS 历史分析段，但当前逻辑槽位里没有对应的 QS 历史图表。
- `P75`、`P89` 分别是 QS 对标高校整体分析和 QS 分指标分析，但当前模板没有对应槽位。

## 严格替换原则

1. 正文替换只按映射文件指定的 `template_paragraph_index` 执行。
2. 不再根据图题前后距离自动猜测。
3. 引导句、章节标题、附录标题默认不替换。
4. 一个槽位可以对应多段正文，例如 `L020` 对应 `P104` 和 `P105`。

## 关键例子

- `L012 / 表5`
  - `P68` 是引导句“位次分布如下”，保留。
  - `P70` 才是表5对应的分析段，应替换。

- `L020 / 图11`
  - `P104` 是比较维度导语。
  - `P105` 是同济在 CNCI/篇均被引上的结果句。
  - 两段都属于图11的正文说明，后续生成时应一起产出。

- `L023 / 附表`
  - 模板只有 `P122` 标题，没有独立说明段。
  - 当前应跳过正文替换。

## 后续给大模型生成文案时的建议

生成时直接读取 `narrative_paragraph_mapping.json`：

1. 按 `logical_slot_id` 找到要生成的段落。
2. 对每个 `paragraphs[]` 子项分别生成对应文案。
3. 保持 `segment_key` 的粒度，不要把多段内容糊成一段。
4. 对 `replace_decision=skip` 的槽位不要补写正文。
