# ESI趋势接入与末章精简

本轮验收范围为八个ESI学科。六个已有对应报告的学科采用已发布Word作为输入，保留排名、对标和论文分析章节，新增ESI趋势章节，并将末章改为三条短要点。地球科学和社会科学总论保留ESI原口径生成专题样例。

## 末章规则

原末章重复排名概览、候选映射说明、长篇论文指标和通用投入建议，单科约1900至2800字。修订后一般为三条、约110至120字：

1. 发展基础只保留一个可核验的趋势或排名事实。
2. 提升重点引用当前同学科样本中的关键指标位置。
3. 建设建议只保留一项与上述证据相关的行动方向。

不在末章重述映射流程、不罗列全部榜单、不自动建议设立专项经费或扩大资源投入。正文表述和指标值从现有已验证数据产物读取，不新增在线模型调用。

## 配置与代码

`configs/runtime/agent_runtime_profile.json` 的 `word_pipeline.editorial_policy_path` 指向 `configs/runtime/report_editorial_policy.json`。该文件集中维护字数上限、ESI对应关系、选择的报告代码、黄色短评和专题样例内容。

`scripts/report_editorial.py` 负责证据读取、短建议、ESI章节插入。原主链路 `scripts/build_word_replacement_trial.py` 已调用该模块，今后重新生成报告时继续使用新规则。

`scripts/build_esi_integrated_reports.py` 是本轮验收入口，无需命令行业务参数。输出到 `outputs/esi_integrated_reports_20261015/`。它只修改原报告末章及新增ESI内容，并在Word刷新目录前，将未编辑的样式、页眉页脚、设置等包部件恢复为源文件原始字节。
