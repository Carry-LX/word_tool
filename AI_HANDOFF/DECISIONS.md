# word_tool 已确定的关键约定

记录日期：2026-10-19。证据主要来自运行配置、`docs/LOCAL_REPORT_DEMO.md`、项目 AGENTS 与导出的两个项目聊天。

| 事项 | 当前采用方式 | 依据 / 原因 |
| --- | --- | --- |
| 用户操作入口 | 本地前端调用已有真实生成器 | 导师需要能看见选学科、过程、报告与抽查的演示 |
| 界面阶段状态 | 从实际后台事件和产物读取 | 便于回看真实节点结果与对应输出 |
| 参数管理 | runtime profile / subject request / 子配置集中管理 | 减少脚本内多处硬编码；入口无 CLI 参数 |
| 并发 | 单次只运行一个报告任务 | 避免图表、Word 和渲染资源争用 |
| 请求隔离 | 每任务请求快照与独立输出目录 | 避免演示修改全局学科请求 |
| ESI 展示 | 保留六个已确认关联，排除两个专题 | 当前配置与文档已明确 |
| 榜单口径 | 单份报告复用选定榜单学科 | 防止综合排名与分项指标跨口径混用 |
| 录屏 | 操作过程与等待连续变速，保留原版 | 保留操作轨迹；不按估计时间拼片 |
| 30 秒分配 | 3 / 8 / 5 / 10 / 4 秒 | 配置 compact_video 的五段设置 |
| 录制视口 | 固定视口；整页截图另用上下文 | 避免录屏画面缩小与灰边 |
| Git | 本地备份；提交前总结并确认 | 用户协作规则；2026-10-21 用户明确授权本轮上传 GitHub |
| 跨电脑迁移 | GitHub 私有仓库存代码及原始数据；Release 存运行快照与 Windows 工具 | 避开大数据库的 Git 单文件限制；新电脑按清单恢复 |
| 临时空间 | 流式打包，每包最多 512 MiB，远端大小与 SHA-256 一致后删除本地分包 | 用户要求节省磁盘；保留原始数据和校验回执 |
| 环境隔离 | 项目 .venv 与 .local；机器专属 Python 写 local_runtime.json | 新电脑无需 Codex，避免改全局业务配置 |
| 交接资料上传 | 只上传人工说明与刷新工具，忽略聊天、快照和自动状态 | 保留本机证据，减少上传范围 |

旧说明按时间和证据使用：根目录 START_HERE 中“未进入 Word 自动填充”等早期状态不能作为当前结论。若新聊天与旧配置不一致，先查当前调用链与用户后续明确决定，更新此文件并注明证据。
